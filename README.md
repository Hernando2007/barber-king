# 💈 Barber King

Sistema web y móvil para la gestión de una barbería, desarrollado como proyecto de portafolio utilizando una arquitectura profesional.

---

## 🚀 Tecnologías

### Backend

- Node.js
- Express
- Supabase
- JWT
- Bcrypt

### Frontend

- Flutter

### Base de datos

- PostgreSQL (Supabase)

---

## 📂 Estructura

```
backend/
frontend/
database/
docs/
```

---

## Funcionalidades

- Registro
- Inicio de sesión
- Gestión de usuarios
- Gestión de barberos
- Gestión de servicios
- Agenda de citas
- Historial
- Calificaciones
- Panel administrador
